# Industry Issue Map

業種別の課題・必要サービス・提案商材を整理するマーケティング戦略マップ

マーケティング会社・広告代理店・SaaS事業者が、業種別の課題発見・営業戦略・SEOキーワード設計・広告訴求・商材開発に活用するための社内ツールです。

---

## 主な機能

### データ管理
- **階層構造**: 大カテゴリー → 小カテゴリー → 業種 → 顧客タイプ → 必要サービス → 課題
- **CRUD操作**: 各階層で追加・編集・削除・複製が可能
- **削除確認**: 削除時は確認ダイアログを表示
- **localStorage保存**: ブラウザに自動保存（DB不要）

### 表示モード（3種類）
- **マインドマップ表示**: 階層構造を横方向に展開。ノードクリックで編集
- **テーブル表示**: 課題一覧。ソート・検索・CSVエクスポート対応
- **カード表示**: 業種ごとにカード表示。クリックで詳細展開

### 課題入力フォーム
- 課題タイトル・詳細・深刻度・予算感・営業優先度
- タグ入力: 既存代替手段・解決策・Akatsuki商材・SEOキーワード・広告ターゲティング
- テンプレート機能: 集客課題・口コミ課題・採用課題など10種類から自動入力

### フィルター・検索
- キーワード検索（全フィールド横断）
- 大カテゴリー絞り込み
- 業種絞り込み
- 深刻度絞り込み
- 営業優先度絞り込み

### データポータビリティ
- **JSONエクスポート/インポート**: データのバックアップ・移行
- **CSVエクスポート**: Excel等での分析用

### ダッシュボード統計
- 大カテゴリー数・業種数・課題数・高優先度課題数
- 深刻度別の課題数
- Akatsuki商材別の課題紐づき件数（上位5件）

### サンプルデータ
「サンプルデータ読み込み」ボタンで以下の業種データを即座に投入:
- 個人経営居酒屋 / 美容室 / 整体・整骨院 / 歯科医院 / クリニック / 買取店 / 中古車販売店 / 整備工場

## ローカル起動方法

```bash
# リポジトリをクローン
git clone <repository-url>
cd MARKET

# 依存関係インストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで http://localhost:3000 にアクセス

## Vercelデプロイ方法

### ワンクリックデプロイ

1. [Vercel](https://vercel.com) にログイン
2. 「New Project」→ GitHubリポジトリを選択
3. Framework Preset: **Next.js**（自動検出）
4. 「Deploy」をクリック

### 環境変数
不要（localStorage使用のため）

### デプロイ設定
特別な設定不要。`next.config.ts` のデフォルト設定でそのままデプロイ可能。

## 今後追加できる機能案

### データ拡張
- **タグ・ラベル機能**: 任意のタグで課題を横断管理
- **商材マスタ管理画面**: Akatsuki商材の追加・編集をUI上で管理
- **業種テンプレート**: 業種ごとのひな形を保存・再利用

### 可視化
- **ヒートマップ**: 課題の深刻度×優先度を2次元で可視化
- **商材別マトリクス**: どの商材がどの業種に多く刺さるかを表形式で確認
- **フローチャート表示**: 課題 → 解決策 → 商材の流れを図示

### 生産性向上
- **AIによる課題提案**: 業種名を入力すると課題候補を自動生成
- **営業資料エクスポート**: 特定業種の課題・商材をPDF/Pptx形式で出力
- **共有URL生成**: 特定のビューをURLで共有

### コラボレーション
- **Supabase連携**: チームでのデータ共有
- **変更履歴**: 編集ログの記録
- **コメント機能**: 課題へのコメント追加

### 分析
- **営業シミュレーター**: 業種×商材の組み合わせで提案スコアを算出
- **SEOキーワード整理**: 登録済みキーワードをシート形式で一覧化・エクスポート
